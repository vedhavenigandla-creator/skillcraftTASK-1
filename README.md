## Task 1: Histogram Visualization

### Objective
To visualize the distribution of numerical data using a histogram.

### Tools Used
- Python
- Pandas
- Matplotlib

### Description
This task demonstrates the use of a histogram to visualize the distribution of numerical data in a dataset. The histogram groups data into intervals (bins) and displays the frequency of values within each interval.
